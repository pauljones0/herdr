---
title: 工作区配色系列
description: 此自定义版本中的工作区主题与协调的标签页配色。
---

在原生客户端中启用：

```toml
[theme]
workspace_colours = true
```

此自定义版本从 24 种命名风格中选择工作区主题，例如 Forest、Pastel / kawaii、Glacier、Sakura、Cosmic 和 Pomegranate。每个工作区生成自己的变体，内部标签页使用相关颜色，无需设置随机种子。

工作区名称不变。侧栏采用 Herdr 主题背景及原有粗体样式，未选中的名称仅带柔和的颜色。选中行使用淡淡的家族色，不再添加箭头、下划线或竖条。代理名称和详情沿用所属标签页色调，工作区详情沿用工作区色调。未选中标签页使用普通面板背景和柔和的彩色文字，选中标签页使用较亮的粗体文字与淡色背景。不依赖终端 DIM 属性，并检查文字可读性。文字对比度同时针对普通和选中背景检查。

添加或关闭标签页会推进配色历史，但不改变工作区主题。移动后仍与邻居协调的标签页保持颜色；否则可以重新分配，并在有限色差范围内额外修复至多两个现有标签页。转移到其他工作区时采用目标主题。搜索无法完全分离邻居时仍保留主题约束。

此版本使用单行横向滚动标签栏。邻接关系按标签页顺序确定，包括溢出的标签页；滚动和调整窗口大小不会重新生成颜色，不会引入原型的多行网格。

配色及随机流状态保存在客户端界面偏好旁的 `*.colours-v1.json` 文件中。同一计算机重新连接相同会话时保留颜色，不同计算机各自保存。关闭选项会恢复普通显示，不删除已保存配色。

## 终端背景

主机报告前景和背景后，客户端可为默认背景添加轻微的工作区色调，保留主机明度，并检查前景及已报告调色板的对比度。无法找到安全色调时使用继承背景。应用程序显式背景和 ANSI 颜色不会被重新着色；浅色终端通常保留继承背景。

这是客户端显示功能。OSC 颜色查询仍返回底层终端主题。Herdr 将恰好等于主机背景的 OSC 11 显式设置表示为默认背景，因此该特殊情况也可能被着色。其他显式 OSC 11 背景保持可见；OSC 111 恢复到可被客户端着色的继承默认背景。

## 性能

渲染读取缓存的 RGB 值。仅当工作区或标签页成员、顺序改变时才进行生成和感知色差计算。先生成 1,024 个样本，需要时扩展到 4,096 个；先检查邻居约束，再考虑新鲜度，并从可行候选中随机抽取至多 256 个评估色调一致性与多样性。修复距离按操作缓存，失败搜索不消耗随机数，磁盘写入在后台线程进行。

这些限制用于控制计算量，并不保证每种排列都可修复。搜索耗尽时仍保持命名主题范围。

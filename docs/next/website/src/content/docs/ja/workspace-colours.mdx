---
title: ワークスペースの配色ファミリー
description: このカスタムビルドのテーマ生成と関連タブの配色。
---

ネイティブクライアントで有効にします。

```toml
[theme]
workspace_colours = true
```

このカスタムビルドは Forest、Pastel / kawaii、Glacier、Sakura、Cosmic、Pomegranate など、24 種類の名前付きスタイルからテーマを選びます。ワークスペースごとにバリエーションを生成し、そのタブには関連する色を割り当てます。乱数シードの設定は不要です。

ワークスペース名は変更しません。サイドバーは Herdr テーマの背景と通常の太字表現を使い、未選択の名前だけに控えめな色を付けます。選択行には薄いテーマ色を使い、追加の矢印・下線・縦線は表示しません。エージェント名と詳細は所属タブの色、ワークスペース詳細は所属ワークスペースの色に合わせます。未選択タブは通常のパネル背景と控えめな色の文字で表示し、選択タブは明るい太字と薄い背景色で示します。DIM 属性は使わず、文字の読みやすさを検証します。文字のコントラストを通常背景と選択背景の両方で確認します。

タブの追加や削除で配色履歴が進みますが、テーマは変わりません。移動後も隣接タブとの条件を満たす色は維持します。必要なら移動したタブを変更し、色差の上限内で追加の既存タブを最大二つ修復します。別のワークスペースへの移動では移動先のテーマを採用します。全ての隣接色を分離できない場合も、テーマ制約を維持します。

このバージョンのタブバーは一行の横スクロールです。画面外のタブも含む順序で隣接関係を決め、スクロールやウィンドウのサイズ変更では色を再生成しません。プロトタイプの折り返しグリッドは追加しません。

配色と乱数ストリームの状態は、クライアントの外観設定の隣にある `*.colours-v1.json` に保存します。同じコンピューターで同じセッションに再接続すると色を維持します。別のコンピューターでは独立した設定です。無効にすると通常表示に戻り、保存済みの配色は削除しません。

## ターミナルの背景

ホストが前景色と背景色を通知すると、クライアントはデフォルト背景に控えめなテーマ色を付けられます。ホストの明度を維持し、前景色と通知済みパレットのコントラストを確認します。安全な色が見つからなければ継承した背景を使います。アプリの明示的な背景と ANSI 色は変更しません。明るいターミナルでは通常、継承した背景を維持します。

これはクライアント側の表示機能です。OSC の色問い合わせは元のターミナルテーマを返します。Herdr はホスト背景と同じ OSC 11 の明示設定をデフォルト背景として扱うため、その場合にも色が付きます。その他の明示的な OSC 11 背景は維持し、OSC 111 でクライアントが着色できる継承デフォルトに戻ります。

## パフォーマンス

描画はキャッシュした RGB 値を読み取ります。生成と知覚色差の計算は、ワークスペースやタブの所属・順序が変わったときだけ行います。最初は 1,024 個のサンプルを生成し、必要なら 4,096 個に拡張します。新鮮さより隣接条件を優先し、条件を満たす候補から最大 256 個をランダムに選び、色調の統一感と多様性を評価します。修復時の色差は操作単位でキャッシュし、失敗した探索は乱数を消費しません。保存はバックグラウンドスレッドで行います。

これらは計算量の上限であり、全ての配置を修復できるという保証ではありません。探索を終えてもテーマの範囲を維持します。
